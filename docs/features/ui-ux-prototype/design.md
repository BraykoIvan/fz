# Лендинг прототипа

Статус: новый вариант на согласование; предыдущие дизайны отклонены заказчиком.

[Проект Stitch «ФЗ — лендинг»](https://stitch.withgoogle.com/projects/11057934093073601834), ID `11057934093073601834`. Создан через Stitch MCP. Дизайн-система: `assets/0da70311b4244bc1b72bff126a8b0570`.

Итоговый экран для согласования: `b0b03fe7c9bc417498a910e5159fd377`. [Первый экран](design/hero.png) · [Полная страница](design/landing.png). Ранние версии в истории Stitch не являются дополнительными экранами приложения.

Один лендинг: крупный первый экран, заметная форма URL и иллюстрация сайта с отчётом; ниже — польза результата, пример ТЗ, четыре проверки и повторное действие запуска. Тёплый светлый фон, графитовая типографика Manrope/Inter, коралловый акцент и мягкие голубые/лавандовые поверхности.

Сейчас оцениваются визуальное направление и композиция лендинга. Экран отчёта, отдельные мобильные артборды, компонентная доска и макет PDF не создаются.

HTML/CSS получены через Stitch MCP и изучены: [исходный макет](design/landing.html). Это демонстрационный дизайн, не реализованное приложение; формы и сообщения в экспорте не являются готовой интеграцией. Проверки рекламы, реквизитов и неподтверждённые обещания времени исключены из состава сервиса.

Tailwind CDN и inline-конфигурация макета при реализации заменяются общей дизайн-системой и shared-компонентами. Реализация приложения не начинается до согласования нового дизайна по [workflow](../../workflow.md).
