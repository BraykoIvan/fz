Для согласования используются эти два итоговых экспорта; ранние варианты в истории проекта не являются дополнительными экранами приложения.

1. **Ввод адреса:** назначение, одно поле, одна кнопка, краткие ограничения.
2. **Результат:** список проблем, факт, исправление, сведения владельца и критерии готовности. Скачивание PDF и санкции доступны без отдельного кабинета.

Основа — типографика, свободное место, тонкие разделители и один синий акцент. Нет маркетинговых блоков, дашборда, плиток показателей, сложной навигации или отдельных досок состояний. Шрифты — Inter и моноширинный для URL/кода; система создана Stitch, asset `ba32dc25c3164f42b3e5057c1381e94d`.

HTML/CSS получены через Stitch MCP, изучены и сохранены: [ввод адреса](design/start.html), [результат](design/result.html). Это статические макеты с демонстрационными данными, не реализация приложения. Tailwind CDN и inline-конфигурация из экспорта при реализации заменяются общей системой токенов и shared-компонентами.

Текущий шаг ограничен этими двумя экранами. Мобильные артборды, отдельный макет PDF и каталог состояний в него не входят; дальнейшие задачи прототипа сохраняются. Для реализации требуется явное согласование этого варианта по [workflow](../../workflow.md).
