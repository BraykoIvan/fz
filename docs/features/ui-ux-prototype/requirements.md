# Лендинг прототипа

Задача: MVP-001. Статус: новый дизайн лендинга на согласование. Дата: 15 октября 2026 года.

Заказчик отклонил подробные доски, затем минималистичный вариант из двух экранов и уточнил: «Выглядит ужасно. Сделай красисый лендинг». Текущий шаг — один выразительный лендинг с понятной формой проверки. Полные требования рабочего продукта остаются в [требованиях MVP](../site-audit/requirements.md).

## Один лендинг

- Сильный первый экран: выразительная типографика, композиция, иллюстрация продукта и заметная форма URL.
- Понятно, зачем проверять сайт: потенциальные проблемы, возможные санкции и план исправлений.
- Небольшие разделы о результате и четырёх проверках первой версии. Демонстрационный пример отчёта — часть композиции лендинга, не отдельный экран.
- Бесплатность, отсутствие регистрации, предел обхода и демо-режим обозначены явно. Нет вымышленных клиентов, отзывов, статистики или обещаний полного соответствия закону.

## Ограничения этого шага

- Новый дизайн создаётся через Stitch MCP. Сейчас не создаются экран результатов, компонентная доска, отдельные мобильные артборды или макет PDF.
- Фейковый результат явно обозначен как демо. Числа иллюстративные, сайт не сканируется; действующие правовые выводы не заявляются.
- Простота пользовательского пути сочетается с полноценным визуальным оформлением лендинга; прежний вариант пустой формы не используется.
- Остальные состояния приложения и shared-компоненты остаются задачами реализации прототипа. Сокращение текущего дизайн-шага не отменяет продуктовые требования и Storybook.
- Реализация приложения сейчас не начинается. Для следующего шага нужно согласовать новый лендинг из [design.md](design.md).
