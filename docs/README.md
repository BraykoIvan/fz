# Документация проекта

- [Описание проекта](project.md): назначение, подтверждённые границы и вопросы для сбора требований.
- [Процесс разработки](workflow.md): обязательные этапы, согласования, артефакты и критерии готовности.
- `features/<feature-id>/`: требования, дизайн, проверки и решения по каждой фиче.

Общие инструкции для ИИ-агента находятся в [AGENTS.md](../AGENTS.md).

Документация должна отражать фактическое состояние проекта. Для неподтверждённых решений указывай статус «предложение» или «открытый вопрос»; для согласованных — дату и ссылку либо точную ссылочную запись на сообщение заказчика. Не сохраняй секреты и персональные данные в примерах.
