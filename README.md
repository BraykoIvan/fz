# Сервис проверки сайтов

Сервис для проверки сайтов на соответствие применимым требованиям законодательства РФ и Роскомнадзора.

Remote: [BraykoIvan/fz](https://github.com/BraykoIvan/fz), локальное имя — `origin`.

Репозиторий подготовлен для начала работы. Функционал, технологический стек и архитектура пока не определены; приложение и тестовая инфраструктура ещё не созданы.

## Структура

```text
AGENTS.md          Инструкции для ИИ-агента
docs/              Документация проекта и отдельных фич
  README.md        Навигация по документации
  project.md       Назначение, границы и открытые вопросы
  workflow.md      Процесс разработки и критерии готовности
  features/        Документация фич
src/               Исходный код приложения
```

Начни с [описания проекта](docs/project.md) и [процесса разработки](docs/workflow.md). Инструкции для агента находятся в [AGENTS.md](AGENTS.md).

Следующий этап — изучение текущего состояния и полный сбор требований с заказчиком. Команды установки, запуска и тестирования будут добавлены после согласования стека и создания приложения.
