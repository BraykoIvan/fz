# Сервис проверки сайтов

Сервис для проверки сайтов на соответствие применимым требованиям законодательства РФ и Роскомнадзора.

Remote: [BraykoIvan/fz](https://github.com/BraykoIvan/fz), локальное имя — `origin`.

Репозиторий подготовлен для начала работы. Утверждены React с TypeScript, ASP.NET Core 10, MediatR, EF Core 10, PostgreSQL 18, Clean Architecture и Vertical Slice. Полное решение — в [описании стека](docs/tech-stack.md). Согласованы основные решения бесплатного MVP: без регистрации и ИИ, до 20 HTML-страниц плюс документы, общий результат на 24 часа и PDF с находками, потенциальными санкциями и ТЗ. Приложение и тестовая инфраструктура ещё не созданы.

## Структура

```text
AGENTS.md          Инструкции для ИИ-агента
docs/              Документация проекта и отдельных фич
  README.md        Навигация по документации
  project.md       Назначение, границы и открытые вопросы
  tech-stack.md    Утверждённый стек и архитектура
  code-standards.md Требования к коду и устойчивости
  documentation.md Требования к API и документации процессов
  violations.md    Каталог потенциальных нарушений и проверок
  mvp-plan.md      Задачи MVP, зависимости и критерии готовности
  workflow.md      Процесс разработки и критерии готовности
  features/        Документация фич
src/               Исходный код приложения
```

Начни с [описания проекта](docs/project.md) и [процесса разработки](docs/workflow.md). Инструкции для агента находятся в [AGENTS.md](AGENTS.md).

Работы декомпозированы в [плане MVP](docs/mvp-plan.md). Сначала создаём болванку приложения с фейковой проверкой для оценки UI/UX: дизайн в Stitch, shared-компоненты, демонстрационный API, полный сценарий и образец PDF. После оценки интерфейса подключаем настоящий аудит. Команды установки, запуска и тестирования будут добавлены при создании приложения на утверждённом стеке.
